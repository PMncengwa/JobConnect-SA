# JobConnect SA

## Project Overview
JobConnect SA is a web-based platform developed to connect unemployed graduates with small and medium enterprises (SMEs) offering short-term and entry-level job opportunities.

## Technologies Used
- ASP.NET Web Forms
- C#
- SQL Server
- HTML, CSS, JavaScript
- Bootstrap

## Features
- Graduate and Employer registration
- Job posting and job applications
- Admin management
- Database-driven system
- Secure authentication

## Purpose
This project was developed as part of my Information Systems studies to demonstrate real-world system development skills.
